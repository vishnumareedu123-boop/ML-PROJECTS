# 💼 Employee Salary Prediction

---

# 📌 Project Overview

This project predicts the **salary of an employee** based on various features such as age, education, years of experience, job role, and other employee-related information using **Machine Learning**.

The project is built using **Python, Pandas, Scikit-learn, Flask, and Joblib**.

---

# 🚀 Features

- Employee Salary Prediction
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Linear Regression Model
- Model Evaluation
- Prediction System
- Flask Web Application
- Model Saving using Joblib

# ⚙ Installation

Clone the repository

```bash
git clone <repository-url>
```

Move to the project directory

```bash
cd Employee-Salary-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶ Train the Model

```bash
py src/train.py
```

---

# 🔍 Predict

```bash
py src/predict.py
```

---

# 🌐 Run Flask Application

```bash
py app.py
```

Open your browser

```
http://127.0.0.1:5000
```
